## 当前源码中的本地修订（2026-11-05 至 2026-11-06，未单独发布）

以下版本沿革描述已发布的 0.3.4 基线。当前源码在其上叠加已批准的设计判断、桌面调研、创意概念、成果/工作环节/子任务路由、隔离方向样张、共用概念探索与选择记录，以及代表页/最终人工确认规则。原十五项的关系已重整：按委托范围确定主/子成果，前期环节可单独委托，平面与印刷合并入口并保留生产分支。产品界面与网站已按确认方案细化九个工作环节，接回原方法、资源及每环节自审，其他主流程仍待逐条确认。保留产品启动门禁、原流程导航、有效主稿和已确认路线，以及全部设计脚本、组件、主题和素材。工具判断统一为 AI 先推荐并说明理由，人在实际制作（含原型、样张）前明确确认；只读可先行，已有适用选择复用。必要早期测试原型不要求先补完整正式 UI，普通高保真任务不默认先画灰框，测试与正式成品分别记录。

原 434 份导入文件的 `source` 与 `source_sha256` 保留；本地修订涉及其中 24 份设计文本，其 `integration_sha256` 保存本地修订前的整合基线摘要，`sha256` 对应当前文件。另有三份本地扩展文档在清单中标为 `origin: local-extension`，不伪造上游来源，包含产品界面与网站的条件加载流程。准确范围见 [design-source.json](design-source.json) 的 `local_refinements`。

本次试跑反馈修订落在现有文本范围：CT7 核对视觉输入；DS1 检查候选差异并由 AI 完成方案推导后直接制作样张、自审供人看图选，不设必经文字审批；V3/TY 区分字体与标题字形；TR4 明确页面子资产边界。U1/U3/V3 共用信息作用与画面表达记录，DS2 从确认主视觉推导整页规格，V7 接分层素材、独立标题与程序信息合成，QA0 检查真实更新/替换及适用动效。独立测试的输入边界、方向来源和不继承历史偏好写入审阅稿，方法正文中的完整案例、具体情境和示范答案均移除，测试内容与产物不入包。文字表达扩至适用的主副标题及眉题，按角色和更新需要选择独立资产；控件、渐变/材质和图形来源按同一视觉语言承接，真实图文组合与复杂表面的检查范围单独核对。图标选择以 V5 为唯一规则入口，接续内容与职责形成图文权重、尺寸和分组规范，核对真实集合及跨组协调；渠道能力、许可、预览与源文件分别验证。配色方法现支持在候选制作前形成整体框架，再校准确认规格；线面重量和 SVG 颜色适配接入同一语义色、组别与状态记录。渐变构成及 Open Props 可选文档入口不代表下载、安装或 CLI 自动集成。脚本/素材保持原字节，未新增字体服务或生图能力；规格未被脚本覆盖的部分仍须逐项核验。

原导入脚本重建上游整合基线；本地修订由 Git 保留，重新导入时须保留并重放这些修订，不能直接导入覆盖后声称与当前源码一致。回归分别检查基线适配可复现、当前文件摘要、本地扩展范围，以及原始 Figma 执行基线与当前文件。Figma 执行入口和四份相关手册的工具确认适配另记在 [figma-source.json](figma-source.json) 的 `local_refinements`，原始来源摘要保留。下面“可重建”“字节未变”等历史描述应在这个版本范围内理解。
