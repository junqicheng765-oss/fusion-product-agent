### UI 制作交接与质量检查增量（2026-11-08）

制作输入接续同一 U3/DS2 的页面职责、区域组织、整体语言、实际参考与资产、组件保留/改造、分层及现用参数；旧参数表和片段标为方向参考，不作为第二套生效值。取消强制命中画面配方及原提供方文件名例外，原流程和确认顺序保持不变。预制资源在原记录中注明实际支持的设计决定、准确版本和落位，未采用部分按实际适用性处理；字体目录不冒称字体文件已加载。

本次有界修订五个导入程序：资源采用检查只核验显式请求的本地有效文件、声明来源与可达引用，区分未请求、未验证和机械结果；不以登记 JSON、文件名、未用样式或重复资产凑证据。几何检查保留真实视口、碰撞与明确面积要求，移除通用旅行对象和大图占比门槛；内嵌 SVG 只提示来源/适配待核，不凭嵌入形式推定手绘。对比工具按 compare/restore 组织材料，像素相似不否决还原，也不证明审美、先后关系或权属。风格读取以 CSS/DTO 的 cssVars 标明生效语义色，原设计色作参考；原生平台保留实际 token/算法与支持的映射边界，一致性检查不从历史说明中收集任意颜色豁免。现有 DTO 色值、组件和素材未改写。

回归覆盖静态引用假通过、重复计数、格式损坏、实际样式依赖、比较输入与还原用途、几何失败保留、预设导出和历史色假豁免。测试夹具仅在仓库 tools 与临时目录，不进入 Skill 分发包；测试使用截图文件与 DOM 单元数据，不冒充浏览器视觉验收。独立只读复核发现的问题经修复和对应回归后再检查。上述结果不能证明新 UI 已更好看；真实制作仍须看准确成品、完成适用成熟参考并排与逐区审查，并保留人工确认。

预设读取另修复 `show --json` 只返回色彩合同、漏掉原存储设计规格的问题。输出补齐非色板的 `meta.dto` 原字段及目录记录，保留空值与未来扩展字段，不填造缺项；设计指导与生效 CSS/DTO 色值、原生平台导出边界分别标明。新增回归覆盖完整目录、实际系统/DTO 规则、稀疏元数据与不变色源；读取修复不证明预设已用于当前 Demo，也不自动取得采用或审美通过。

资源采用链条同步到制作入口、DS2、QA0和原模板：读取相关完整规则后区分默认参数与可复用规则，优先保留适用部分、改造必要差异，再推导真实缺口；不能仅因默认配色/圆角整套排除或以任务推导跳过适用规则。核对准确源规则、任务实现与同版成图，区别查阅、采用、改造、未采用及整套/局部范围。有效主稿、真正不适用、自主表达和非 UI 成果边界保留，不强制套预设、导出全套主题或凑采用数量。本项仅修订方法及包检查，按用户范围未重做或测试 Demo。
