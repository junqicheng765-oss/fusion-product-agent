# 全局视觉参考库

本库随 `fusion-design-core` 分发，供所有适用视觉成果检索：品牌、海报、包装、演示、信息图、文档、视频风格帧、界面中的主视觉与字形等。产出物不限制参考来源；按当前决定需要借鉴的部分跨媒介转化。参考画面、可复用资产、真实字体、交互证据分别判断。

本版包含 106 张经查看的非 UI 图片，按内容哈希去重。完整 UI、实际 App／网站截图、活动界面与界面展示板不随库打包；界面参考按 [RR](../methods-resource-routing.md) 在线检索。海报中的搜索形宣传提示或进度意象不自动视作真实 UI，也不能据其推定控件行为。含 UI 的原始图不为保留头图而整张混入。

## 文件与发现

- `images/`：实际图片，每份只存一次，不依赖作者电脑、外部图床或网络缓存。
- [catalog.json](catalog.json)：每图的构图、风格、材质、字形、配色、图形标签、观察与使用边界；同图可支持多个角色和检索入口。
- [visual_reference.py](../scripts/visual_reference.py)：标准库 CLI，从脚本自身位置解析库；安装到其他项目后仍可检索真实图片路径。
- 包级 `visual-reference-source.json`：独立的收录／排除哈希与来源登记。出处由文件名推测的链接明确未核实；收录日期不冒充原作日期或授权。

在本 Skill 目录执行，或用已安装脚本的实际路径调用：

```text
python3 scripts/visual_reference.py list
python3 scripts/visual_reference.py search <关键词> --role <角色> --family <入口> --limit 6
python3 scripts/visual_reference.py show <图片ID>
python3 scripts/visual_reference.py validate
```

`list` 只列入口和角色计数，避免每次加载整个图集。`search` 是按词检索，多词以空白分开；命中及顺序只帮助定位，不能证明适配、美观或流行。`show` 回传本次安装位置的真实图片路径。需要看图时打开实际文件，不能把返回的标签当作已经看过图片。查询无合适结果时改变检索角度或在线补充，不用不相关图片凑数。

## 入口不是待执行的风格清单

| 入口 | 主要检索范围 |
|---|---|
| `tactile-3d` | 触感材质、玩具、微缩和立体场景 |
| `paper-collage` | 折纸、纸雕、票据、手账、摄影拼贴 |
| `illustration-print` | 手绘、几何、漫画、波普、颗粒与印刷表达 |
| `type-graphics` | 字形、字效、排字、字图共构及抽象图形 |
| `photo-scene` | 人物、商品、生活、空间与场景叙事 |
| `optical-tech` | 光学、玻璃、金属、光轨及科技质感 |
| `cultural-oriental` | 文化符号、年俗、传统器物及当代表达 |

入口可以交叉，不宣称互斥或穷尽所有审美。针织、刺绣、块面字、路径排字、强透视、包装内空间等另作细标签，不为每个手法新建一套完整风格。库存较多仅表示本次提供较多，不能据数量偏向某种媒介。已有参考可提炼的手法不反复要求人补图；缺某分支也不阻止使用其他适用参考。

`role` 分为 `composition`、`kv`、`lettering`、`palette`、`material`、`icons`。同图的某个字形或材质成立，不等于整幅图适合本任务；实际用途须指向区域和关系。

## 按任务、质量与当前语境筛选

1. 先承接该成果的必要专业判断、内容主次、品牌、受众、渠道与审美约束，明确这次要支持什么表达。已有确认方向按范围复用；不为查库重做已有效的决定。
2. 需要新方向时，结合目标市场和相关行业的近期实际作品，看目前有哪些成熟表达；再按当前任务检索本库的构图、字形、材质或工艺。两者可往返印证，不把库存、风格名单或先想到的物件当作默认答案。
3. 先看表达适配与完整设计质量，再看近期性和趋势信号。感知触感、手作拼贴、个性标题、超现实场景、精致光学或克制编辑等可以作为当轮线索，是否值得优先看取决于任务和实际作品，不固定排名、不轮流尝试所有入口。旧作可支持技法；本库原作日期未知，不能独立证明当下流行。
4. 只展开少数成立的方向。按 [DS1](../methods-style-engine.md) 的适用数量制作实际候选，不先逐类生成再筛。比较两案时，可使一案从近期真实案例提炼，另一案从任务背景和审美约束独立构思；后者仍要找适用参考支撑。起点不同不自动证明画面有区别，也不增加无图方案审批。
5. 每张选中参考说明借鉴什么、为什么、用在哪里、哪些不继承。整图、局部、画面质量标杆分别记录；一张图可承担多项，但不能以局部字效为整案背书。参考的品牌、文字、人物、规则和数据不自动成为当前任务内容。
6. 生图继续执行 [V7](../methods-visual.md)：打开并判断实际图片，按构图、字形、材质等角色挑必要的图，把它们与本轮构成提示词通过工具真实图片参数提交。可配合本轮线上找到的参考，不能只提交链接、风格词或整库图像。保留实际文件／图像 ID、角色、参数和成图版本；工具收不到图片时如实处理。
7. 生成后照原方法检查实际成图。参考选得好、已垫图或工具成功均不代替工艺、整体组合、信息、差异和人的看图确认。字形参考图不等于可输入任意文字的字体；动态内容与分层制作仍按原规则。

本库服务界面时，可以支持主视觉、字形、配色与材质；流程、控件行为及状态仍从当前可用的线上产品参考与专业方法取得证据。线上参考保存在当前任务中，不因搜索或下载就自动加入分发包。

## 趋势依据的时间边界

2026-11-07 查阅的 [Adobe 2026 创意趋势文章](https://blog.adobe.com/en/publish/2025/12/09/four-creative-trends-define-marketing-2026)讨论触感、人际联系、超现实趣味和本土文化；[Canva 2026 设计趋势](https://www.canva.com/design-trends/)同时包含材质、手作记录、变形现实和结构化简洁等不同线索。这是有来源的年度观察与预测，不是所有行业的流行度排名，也不证明本库每张作品近期发布。

后续任务涉及“当下”“最新”或具体市场偏好时，按执行当日重新核对相关近期作品及原作日期，以实际观察说明对本轮筛选的影响。不能永久沿用本次趋势记录，也不能用趋势报告替代作品看图。

## 包内维护

新增图片先实际看图、排除 UI、去重并确定可借部分，再更新标签、三类索引及独立来源登记；图片路径须在本库内，索引不应含作者机器路径。来源或授权未知如实标明，视觉学习参考不等于已获准直接复用成品资产。

本库及新增 CLI 在 `design-source.json` 中以 `bundled-visual-reference` 独立登记，原有导入基线和三份方法扩展不改。重新运行上游导入脚本会覆盖来源登记；导入维护时须保留并重新登记本库及已批准的方法改动，不能把新资源丢掉或伪装为上游原件。

资源或规则改动后，先更新来源登记并运行仓库 `tools/build_manifest.py` 刷新字节清单，再执行 CLI 的 `validate`、仓库 `tools/test_visual_reference_library.py`、原有包检查和来源回归；安装回归依赖准确的当前清单。结构、检索与安装检查不证明审美效果。
