# Figma 执行前核对卡

版本：v0.6｜用途：在实际 Figma 写入前确认目标、权限、边界和证据要求；它是 执行就绪 设计就绪的必要检查，不替代产品原型、设计任务包或产品评审。

## 1. 适用与状态

高保真 Demo、Figma 生成、设计稿补页或既有画板精修，均在执行前创建 `product/handoff/design/DESIGN-<模块>-执行前核对卡.md`。没有实际 Figma 写入时，不必创建空卡；可以生成“未绑定 Figma 目标”的设计任务包，并明确其状态为“材料已准备，未进入 执行就绪”。

## 2. 必须核对的信息

先按 [设计能力初始化与复用](initialization.md) 引用已有配置与文件绑定；同目标、同权限和有效授权范围不重复配置或索取批准，只补本次任务包、动作及回传差异。新目标由用户指定，代建文件须有明确要求。

| 项目 | 必须记录 | 不满足时的处理 |
| --- | --- | --- |
| 工具路线 | TR0 推荐与理由、人的明确选择或既有批准来源、目标及适用范围。 | 未明确确认时只读核对或准备，不提交生成/编辑。 |
| 产品输入 | 当前产品正文版本、SC/UC、R、UX、AC 及设计任务包版本。 | 返回产品/设计任务包补齐，不开始写入。 |
| 文案输入 | 当前界面文案基线入口/版本、本次COPY ID及原文、审查就绪、动态约束和需制作后验证的适用要求。 | 返回产品文案步骤，暂停受影响页面正式制作；只读配置/资产核对与无关研究可继续。 |
| 异常页面对应 | 适用时取得实际对应表/有效版本，本轮行为与COPY就绪，设计已明确呈现/阻断、操作与输入/状态更新；无稿时待制作后回填实际节点。 | 仅暂停缺少必要规则、文字或呈现依据的相关正式制作；不要求先有实际成稿或全系统表，不阻断无关工作。 |
| 异常呈现分流 | 适用时引用已有对应表/任务包中的资产核对、复用/修改/变体/新增页/仅取证计划；新独立页有任务及不可复用理由，保留原异常覆盖。 | 先核对/补足受影响的分流，不把每条异常默认交给生成器画整页；不新增逐页批准。 |
| 目标定位 | Figma 文件名/链接或稳定标识；页面；Frame/选区；目标对象的当前版本。 | 只准备任务包，不能声称设计就绪。 |
| 执行者与工具 | Figma 执行者（Agent/设计师）、可用工具、账户/会话和真实可执行能力。 | 改为交给设计方的任务包，或等待条件具备。 |
| 授权 | 谁授权、授权日期、允许的动作和范围。 | 不读取/写入/覆盖外部设计。 |
| 写入范围 | 可创建、修改、移动、删除的页面/Frame/图层范围。 | 不执行可能影响既有内容的动作。 |
| 受保护对象 | 不得覆盖、移动、删除或改写的页面、组件、变量、资产和既有已确认 Frame。 | 将对象列入任务包禁止项，无法识别则受阻。 |
| 共用定义 | 本轮共用基线入口/版本、适用项/变体、实际组件/变量来源及共享修改影响；小改动可引用现有章节。 | 缺少会影响行为/范围的定义先补受影响项；不阻断无关研究或要求新建全库。 |
| 视觉基线 | 设计系统/组件库、品牌资产、内容密度、响应式与无障碍约束。 | 标为探索范围，不把猜测写成视觉基线。 |
| 证据与回传 | 应返回的页面/节点、截图/导出、状态覆盖、差异和责任人。 | 不开始 设计回审 回审或声称设计完成。 |

## 4. 通过与停止规则

执行就绪 仅在上表所有必填项可定位、产品基线没有影响本范围的阻断、设计任务包可观察验收完整时通过。目标、授权、写入范围或受保护对象任一未知时：可以继续产出或修改任务包，不执行受影响写入，不称“等待 Figma 执行”，不把任务包生成视为设计通过。初始化或现状核对的只读访问限于用户提供且获授权的目标，不以缺少写入授权阻止已授权读取。

执行完成只进入“已执行待回传”。只有产品负责人根据真实 Figma 节点/截图/导出和覆盖矩阵完成回审，才能进入 设计回审。
