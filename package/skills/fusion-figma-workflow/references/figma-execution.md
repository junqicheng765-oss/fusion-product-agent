# Figma 生成与直接精修手册

只在实际 Figma 执行时读取。当前宿主的工具使用限制与必需操作指引仍适用；本手册不假定某个全局 `computer-use` Skill、固定运行库或桌面系统存在。没有可调用的底层工具就先引导配置，不编造点击或执行结果。

## 操作前

恢复本任务设计能力配置及 [Figma 执行前核对卡](preflight.md)。核对任务包版本、实际应用/文件/页面/Frame、允许动作、保护对象、组件/素材和可观察验收。目标可读不证明可写；不得向错误文件提交提示词或把画布当前选择默认当成本任务目标。

主 Agent 已形成设计任务包时，沿用其中专业提示词与验收，不自行补业务规则；缺少事实先返回主线。旧页修改没有生成提示词也可直接精修，不为满足模板调用生成。

## Computer Use 的共同操作方法

1. 用当前宿主实际提供且获授权的界面观察能力定位应用，读取新鲜的无障碍信息或截图；核对真实文件、页面和目标对象。
2. 每次切换、点击、输入或提交后重新观察。页面变化后不复用旧元素索引或仅凭旧截图坐标连续操作。
3. 写入前确认选区、属性面板或输入框作用范围。多行提示词可用宿主支持的粘贴输入，发送前核对完整内容与目标；不通过未声明的系统脚本替代宿主规定路线。
4. 同一执行标识/步骤只提交一次。超时、失联或暂时看不到反馈标为结果未知，恢复后先查原执行，不能盲目重发造成重复页面。

## 旧页直接编辑

定位具体图层/组件与当前属性，优先复用实例、变量、字体、图标和已有资产；根据任务包调整文字、位置、尺寸、间距、布局或可见状态。不要让 Figma Agent 为局部问题重新生成整页。

每批修改后查看实际画面或导出，检查改动对象、相邻内容、全局菜单与共享组件影响；不要为一处修改删除动态状态或受保护图层。无法可靠定位时暂停该对象，返回具体缺口，不转用自然语言反复重画。

## 存量设计资产与下游可接入性

在修改范围和必要相邻页面中识别当前有效组件、Variables / Styles、字体、布局/密度、图标、素材及状态规范，记录对应节点/库和版本。新增整页也沿用这套基线，不能因新页面就重选风格、重造全局主题或用通用模板覆盖既有设计。

优先复用组件实例并继承变量，不为生成方便随意拆散实例、重建变量或修改全局组件。确需新增组件/变体/状态时，在允许范围创建并说明原因、命名和与既有资产的关系；变更共享组件须回查受影响页面，重大偏离由主Agent收集决定。

生成任务显式带入可访问的组件/变量、真实素材和代表页面，生成后核对实际实例/样式和画布，不凭提示词“沿用风格”判定通过。回传沿用/新增/变更清单、准确节点与版本，以及与现有代码组件/Token的映射；不能映射的项标明接入工作，不保证设计稿直接生成即可上线。

## 新整页生成后精修

核对当前实际 Figma Agent/插件入口及账号可用性，输入产品任务、页面职责、内容/状态、现行组件与风格、目标和保护范围。工具提供的其他生成方式只有在当前路线允许且确实可用时采用，不伪称调用 Figma Agent。

提交后观察运行与真实结果，保存新增 Frame/节点；若只得到代码、预览或截图而没有任务要求的可编辑设计，记录实际产物与缺口，不称画布稿已形成。生成结束后再通过直接编辑精修，不同时对同一范围发起生成和修改。

无基线的三套风格候选保持同一代表页、内容和状态，均在授权目标内；由主 Agent 收集选择后再扩展。有有效设计基线则沿用，不为每个新增页重选风格。

## 核验、停止与返回

按任务包的验收项对照实际画面，检查文字、结构、组件、关键状态和范围。保存实际结果链接、节点及截图/导出；未观察的交互不能由截图推断通过。

回传任务包版本、执行标识、实际改动/生成范围、结果证据、已通过/未通过/未观察项、保护范围影响与下一动作。提示词已发、Agent 运行完成和产品审阅通过是不同事实。

收到停止要求立即停止新动作。已有外部生成正在运行时，只在真实观察到停止后报告已停止；否则保留结果未知及已有产物，恢复前先核对原执行，不删除历史或晚到结果。
