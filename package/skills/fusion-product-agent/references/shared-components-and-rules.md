# 全局共用组件与规则：同一依据，按需复用

适用于界面设计、存量迭代、跨页展开或共享项变更。先看本轮及必要相邻页面的现状，不为咨询或单点修改启动全产品规范建设。产品主线维护业务含义与来源；设计专家沿用自身交互、组件、风格和QA0方法，补齐共享交互与呈现，不由本文件另定视觉风格。

## 何时形成，以及形成到哪里

- 方案/交互明确时识别反复出现的任务、行为与规则。正式代表页制作前先确定其实际用到的共用项；代表页产生的新共用定义经自检回填后，才供后续页面展开复用。不要求提前冻结全系统组件。
- 存量项目先查已有产品规范、设计库、组件文档和实现。有效且适用的直接引用；缺口才补。未知或互相冲突的来源如实记录，不能把一次页面样式当全局规范，也不顺带改造存量系统。
- 多模块可用[共用基线模板](../assets/shared-baseline.md)；小需求在当前正文/设计任务加一个共用项章节即可。已有等价目录直接补字段，不重复建表。没有新共用项时说明沿用的来源与范围，不造空库。

## 基线是一份来源与使用关系索引

保留既有稳定ID；只有新增项确需跨页引用时才补稳定标识。每项能回答以下问题，可引用现有章节，不强求每项独立文件：

| 内容 | 最低可用信息 |
| --- | --- |
| 职责与适用范围 | 解决什么任务、适用端/角色/场景；不适用情形 |
| 共用行为 | 输入、触发、动作、反馈/状态、取消/返回及必要约束；业务含义引用规则正文 |
| 权威来源 | 业务R/场景/验收引用；准确文字引用COPY基线与版本；外观引用设计库、Token/变量和有效源版本 |
| 变体 | 允许变化的参数/状态；确有业务差异的局部变体及理由，不能把局部例外默认为全局 |
| 使用位置 | 采用它的页面/状态或可定位引用；实际Figma节点、前端组件路径仅在已取得时填入 |
| 状态与验证 | 本轮有效版本、草拟/可制作/实际采用状态、可观察验收与未验证项 |

同一共用项只有一处有效定义。业务规则、准确文字和视觉值各自仍以已有权威源为准；这里建立关联，不复制出另一套可独立修改的规则、文案或Token。派生文档展示原文时标明来源和版本，变更回原源维护。页面写“共用项ID/版本 + 本页输入/差异 + 引用”，不整段重写通用行为。

## 如何判定共用与差异

先看职责和业务语义，再看外观。相同的确认、表单校验、反馈、导航或加载行为可共享；是否适用按真实项目判断，不要求每种组件齐备。全局规则可以约束多个不同组件，例如同类字段何时校验或返回时如何保留输入，但必须有适用范围和规则依据。

使用同一基础组件不代表业务规则相同：不同对象、权限、后果或恢复方式分别引用自身规则和COPY，必要时形成命名变体。颜色/尺寸相似不足以合并；页面不同也不足以复制一份。找不到可复用项时说明新增职责；组件库缺失不等于可以伪造实例、节点或代码映射。

## 设计、Figma与正式前端如何消费

1. 产品任务包带入共用基线入口/版本、本轮使用项及业务/COPY来源；动作未明确时先交互推导，再补文案，不因缺文案阻断无关研究。
2. 设计按既有U4、DS0–DS4选择和映射组件；优先复用现有实例、Variables / Styles及实际组件。代表页与跨页展开回传采用/新增/变体及位置。发现产品语义变化回主线，不在页面里悄悄改规则。
3. Figma执行前核对本轮共用项、目标组件和保护范围。生成提示词携带实际可访问资产与行为引用；生成后检查真实实例/变量及页面行为要求，不以写过“沿用组件”当作已复用。截图只能证明外观，不能证明组件结构或动态交互。
4. 还原承接同版主稿、共用项与COPY版本，先映射实际已有前端组件/Token，再增量处理缺口；避免每页复制一套样式和行为。不存在的实现只记接入工作，不声称已复用或可直接部署。职责和执行权限沿用主线合同。
5. QA0和产品交接引用同一基线。按使用位置检查共享行为/状态、合法变体、文字和实际设计/前端对应。设计检查与动态操作分别记录；一页通过不代表所有使用页通过，也不把代码形似当实际共用。

## 共享项变更与影响检查

修改前查使用关系，列出受影响页面/状态、变体、业务/COPY/视觉来源、Figma和前端映射及对应验收。修改权威源后更新当前引用与采用记录；不同载体版本号不必相同，但须明确覆盖同一有效定义。发现旧引用、局部覆盖或冲突，先修正或标明受阻，不能只改版本号宣称同步。

只回查实际受影响范围，同时检查本轮未改但仍使用该共享项的已知位置。未知使用方或无法运行的页面写明覆盖缺口与下一核对动作，不宣称全局验证通过。改变全局语义、品牌风格或已确认重大取舍时回原决定点；普通复用、映射与不改变已确认含义的修正直接完成，不增加逐组件审批。

在既有成果摘要说明本轮沿用/新增/变体、重要影响与未覆盖，并提供有效基线入口。详细列表留在产物里，不每轮重贴全库；文案有审查或变更时仍展示既有文案审查摘要。此基线只解决共用定义与引用；异常分层沿用原规范，不把共用项清单扩成新增页面清单。
