# Figma与设计工具接入

本文件只负责工具和权限接口，不规定设计制作顺序。UI制作/转换、存量延展与按正式稿还原，执行 [设计专家主入口](../../fusion-design-core/SKILL.md)及其 [工具路由](../../fusion-design-core/methods-tool-routing.md)。原融合包“有Figma则一律先改Figma再做Demo”的优先规则已移除。

启动设计任务时检查宿主实际可用的Figma MCP/转换能力、浏览器、Computer Use、生图与素材能力，区分已配置、已认证、可读目标、可编辑目标和实际运行成功。已有有效配置记录且权限仍适用时复用；缺少能力时按设计专家规则选择替代工具，用户指定格式无法交付时如实指出受影响结果。安装Skill不会自动获得账号、付费素材或文件编辑权限，不声称所有宿主都提供同名工具。

需要Figma输出或访问现有稿时，取得用户指定的文件/节点，明确参考稿或编辑目标、允许编辑范围、受保护内容和版本。优先复用指定链接，不擅自创建项目、覆盖原稿或换目标文件。没有目标时通过原生提问请用户提供链接或明确允许新建，不能把未回答当作授权。

当前设计模块的新建UI路线是本地组件/主题/真实素材形成高保真页面，确需Figma时再通过实际可用的转换接口进入Figma；不调用Figma云端Agents重画该页面。这是同事最新模块的方法，不能再用旧融合包流程覆盖。已有正式稿还原按其对应分流执行。用户另有明确路线约束时先说明冲突，不能偷偷换载体后称完成。

IconScout的插件MCP声明在包根目录`.mcp.json`；项目级Skill/Subagent安装只复制资源，不改宿主MCP配置。按设计模块的素材方法检查已连接服务或使用同包脚本，不重复建立已有连接。Figma服务按宿主官方配置引导，授权操作交给用户；本包不携带账号和访问令牌。

回传实际使用工具、文件/节点/版本、输入输出对应、画布/截图/代码与运行证据、未覆盖和恢复动作。服务返回、可编辑图层、静态检查、动态体验和用户确认分别表达。
