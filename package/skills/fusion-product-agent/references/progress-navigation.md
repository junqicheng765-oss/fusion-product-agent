# 流程位置展示与下一步引导

用于产品启动、续做、成果/修订回复、提问、阶段切换、返工和收口。产品主入口组织显示，设计/Figma模块回传真实位置；直接调用模块也遵守本说明。

## 产品主线：固定六个位置

| 位置 | 阶段 | 本段重点 |
| --- | --- | --- |
| 1/6 | 目标与范围 | 理解想法，校准用途、使用者/场景、核心范围及本轮终点 |
| 2/6 | 领域需求与系统边界 | 研究依据，构建对象、规则、责任与上下游边界 |
| 3/6 | 方案与任务流程 | 比较方案，讲清核心任务、流程、关键取舍和验收预期 |
| 4/6 | 设计与代表体验 | 承接有效产品输入，完成设计并验证代表性可操作链路 |
| 5/6 | 模块展开与体验收敛 | 扩展约定模块、状态与异常，增量设计、复核和收敛 |
| 6/6 | 详细规格与交接 | 展开PRD、验收、依赖与接收任务，校对有效版本组合 |

这是既有工作主线的导航坐标，不是六轮审批或完成百分比，不替代具体产品/设计方法。合并执行仍沿用编号，说明本轮覆盖范围；不能按回复次数前进，也不能因文件写完、QA通过就自动标为用户确认。局部返工保留主线位置，另写回查范围；不能用其他独立工作完成掩盖关键阻断。

## 设计环节：沿用设计专家的四步

| 位置 | 设计步骤 | 对应实际方法 |
| --- | --- | --- |
| 1/4 | 研究与流程交互 | 接单分诊、语境/研究/竞品、流程与具体交互方案 |
| 2/4 | 视觉方向与设计决策 | 复用既有风格或选择方向，形成组件/素材与设计决策依据 |
| 3/4 | 设计制作与Demo还原 | 按有效路线生成/精修、组件与素材制作，按本轮终点还原Demo |
| 4/4 | 设计复核与回传 | QA0、文案/交互专项检查、修正复验及产品回传 |

四步对应同包设计主入口的实际工作，不另建新的设计方法。产品第4或第5阶段可多次进入这四步；同时注明当前模块，避免把某个模块通过写成全产品完成。Figma配置/权限/目标核对是执行准备，先写“当前：设计准备/配置”，不为了分母把它算成已完成的设计步骤。

存量延展、严格还原或局部修改复用已有效步骤并说明依据；不为了展示重做调研、重选风格或增加批准。没有足够依据定位当前步骤时先恢复状态，写清“位置核对中”和实际动作，不编造编号或完成状态。

## 每次结果的第一行

完整产品任务使用：

```text
产品第 {n}/6 阶段「{阶段名称}」｜当前：{具体动作}｜{真实状态}
```

进入设计以后使用：

```text
产品第 {n}/6 阶段「{阶段名称}」｜设计第 {i}/4 步「{设计步骤名称}」｜{真实状态}
```

例如：

```text
产品第 1/6 阶段「目标与范围」｜当前：校准首期使用场景｜等你选择方向
产品第 4/6 阶段「设计与代表体验」｜设计第 2/4 步「视觉方向与设计决策」｜等你选择风格
产品第 5/6 阶段「模块展开与体验收敛」｜设计第 4/4 步「设计复核与回传」｜房间模块复核完成
产品第 6/6 阶段「详细规格与交接」｜当前：交接版本校对｜本次产品交付完成
```

填入真实内容，不输出占位符。状态区分进行中、已产出待复核、等你选择/补充、工具受阻、本阶段完成和本次任务完成；只有真实存在未解决的关键决定时才写“等你确认”。本阶段或设计环节完成，不等于整个产品任务结束。

只咨询、只评审、明确局部修改、锤子能力迭代等独立任务，用“任务「任务名称」｜当前：具体动作｜真实状态”，不套六阶段。已在产品主线内的局部回查保留主线位置。只要求做到方案或设计时，注明本次终点；到达后可以结束本次任务，不假称其余阶段已经完成。

首次展示紧凑六阶段路线和本次终点；后续每条成果回复保留位置行即可。进入设计时展示当前适用的四步及复用/不适用范围。阶段切换或范围变化说明已完成什么、进入哪里和依据；不每轮重贴全部流程。

## 结果结尾与状态恢复

- 无需人决定时：写清接下来由Agent产出什么，并在授权、输入允许时继续实际执行到真实审阅点；不以“以后会继续”结束，也不只报完成让人自己猜下一步。
- 需要人时：给本轮成果入口、此次审阅/选择范围、推荐与回复方式，实际调用原生Question；答案后进入哪个步骤说清楚。不为了状态行创建新的确认点。
- 持久项目在现有状态入口保存路线/终点、产品位置、适用设计步骤/模块、真实状态、有效决定、未决影响、下一动作及更新时间。恢复时核对新的人类输入，不依靠聊天轮数猜进度。轻量任务可复用正文，不强制另建台账。
- 导航放在协作回复、成果说明和状态入口。不要写进最终用户使用的Demo页面、按钮、弹窗或产品文案。它也不能替代产品启动条件、实际QA、用户决定与交付验收。

本说明是执行规则，实际是否每轮展示、是否正确恢复与引导需真实对话验证；静态包检查不能证明流程遵循率。
