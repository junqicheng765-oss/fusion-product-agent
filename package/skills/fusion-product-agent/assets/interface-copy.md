# 界面文案基线：<产品或模块>

## 有效依据与范围

- 基线版本、更新时间、当前状态：草稿 / 已审查就绪 / 局部阻断 / 已替代。
- 当前产品正文、用户与情境、流程/页面职责、规则及有效决定的入口与版本。
- 本次覆盖的页面/状态/共享组件；未覆盖及受阻范围、原因和恢复动作。
- 沿用的现状文案/语言规范；仅为候选的假设和需要人判断的事项。
- 文案内容由产品主线编写审查；设计按本版使用。Agent自检与人工决定分别记录。

## 本轮审查摘要

供成果回复直接引用，展示规则见[文案审查摘要](../references/product-copy.md#可见成果文案审查摘要)。本节概括下方记录，不成为另一份可编辑的正式文案表。

- 本次性质与版本：新编并审查 / 局部修订复查 / 复用；当前版本、对比版本及来源；首次编写无项目旧版时如实注明。
- 范围与方法：本轮页面/状态/共享组件、未覆盖范围；实际采用的质量判断与事实依据。
- 关键变化：引用下方修改记录中的代表性COPY ID、位置、前后变化和原因；无修改时如实说明，不编造发现。
- 内容结论：就绪/局部阻断及具体影响；实屏/动态验证另列真实完成与未覆盖。
- 下一动作：设计采用版本及下一产物，或阻断的处理方、恢复条件与必要决定。

## 异常引用（按需）

已有异常清单时仅引用其入口，不再复制一套映射；否则可在本基线内合表记录异常ID、规则/状态、COPY ID与有效版本。同一文字只有一处可编辑的有效值，页面规则通过异常ID引用，不因页面数复制条目。

## 设计交接与版本对应

- 本轮就绪条目/范围及阻断条目；就绪依据与审查记录。
- 设计任务包引用本基线版本、适用COPY ID及原文；执行提示词含必要原文和变量约束及需制作后验证的适用要求。
- 本轮适用的方向样张沿用同一代表页文案；设计不现场补字或改写。变化回到此基线修订后同步。
- Figma/本地设计和Demo的实际版本及文案对照记录入口；未制作、未实屏检查或未动态验证分别标明。
- 业务/品牌等关键人工决定及来源；普通表达已授权由Agent完成，不逐句求确认。
