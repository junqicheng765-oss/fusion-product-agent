# 产品到设计的任务输入

## 当前依据

产品正文入口与准确版本；业务目标、目标用户与特征、设备/使用情境；领域证据与未证实假设；有效决定及确认/委托范围。

## 任务和规则

对象、角色、权限、关键规则及其引用；用户主任务、必须覆盖的状态/异常与恢复；业务验收预期。本轮必做、不做及终点。已有页面/交互提案供设计专家审视，不锁死具体控件或视觉。

## 现状与边界

现有Figma/截图/运行界面、设计系统、组件与素材来源；参考和编辑目标分开；有效文件/节点、允许修改及受保护范围。已有研究、竞品、风格选择和授权记录；缺失资料如实标明。

## 交付合同

约定格式、用途与接收者：浏览器高保真/可操作Demo、可编辑Figma或其他成品；必要账号/工具/素材条件与实际状态。设计专家按自身流程建立设计决策与工具合同，不由产品预设旧设计步骤。

## 设计回传

设计决策记录及用户选择、实际成品/节点和版本；页面/状态—场景—规则—验收对应；组件主题素材来源；QA0三维结论、真实脚本/看图/操作证据、差异与未覆盖；需要回到产品主线处理的业务变化。
