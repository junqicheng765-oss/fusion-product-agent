# 当前工作状态

按有实质变化时更新，不为每轮建快照；小任务可内联正文。

| 项目 | 当前值 |
| --- | --- |
| 本轮问题与终点 | 写本次任务及完成判据 |
| 产品主线位置 | 第几/6阶段、名称、依据；局部独立任务写任务范围，不编造进度 |
| 当前设计位置 | 适用时写第几/4步、当前模块、复用项；尚未进入或不适用如实写明 |
| 产品启动与设计依据 | 目标/核心范围的来源或委托、关键意图是否足够、未决对制作的影响；等待回答时不写成已确认 |
| 界面文案基线 | 入口/版本、就绪/阻断范围、编写与审查结果；设计/Demo实际使用版本和实屏对照记录，不把文字自检当实屏通过 |
| 文案成果展示 | 最近一次审查/修订性质、摘要与关键差异记录入口、残留及下一动作；是否已在最终回复展示/尚需展示、对应回复或时间。不重复展示无变化的旧发现，不把保存文件当用户已看到 |
| 设计产物性质与有效源 | 本轮探索/正式设计/按稿还原及真实状态，源入口/准确版本/范围；Figma或明确本地路线依据，正式交付检查结论及证据，模拟/未接入说明入口；不把探索稿自动升级为主稿 |
| 正式前端体验与服务接入 | Demo按目标生产规格对照的画面/交互/文案版本、完成项与必要缺项、实际证据；本地数据/受控返回及后端未接入另列，不能以“Demo”豁免前端缺项 |
| 共用组件与规则基线 | 入口/版本、本轮沿用/新增/变体、实际使用页与映射；共享变更的影响/复核和未知覆盖，小需求可引用现有章节 |
| 异常页面与文案对应 | 适用时写实际产物入口/版本、就绪/阻断与覆盖；R/状态/共用项/COPY/AC及设计/前端采用对应，未核实能力和未动态验证单列 |
| 本地前端与技术执行边界 | 本地体验稿目录/可改范围、受保护项；生产工程与Git操作的技术接收方、允许操作及依据，不能把体验稿确认当提交授权 |
| 技术接力状态 | 当前任务/输入版本、材料准备/已发出/真实接收或执行/返回待核对的实际证据；缺调用机制/授权/接收者时的材料入口及下一动作 |
| 当前成果与位置 | 正文、设计、Demo等实际入口与适用版本 |
| 领域构建与取证 | 锤子补齐的知识、已查来源、组织事实缺口及下一取证动作 |
| 价值验证位置 | 交付、采用、付费/收益的实际证据与下一验证任务 |
| 有效决定/委托 | 可定位来源、范围与效力，不用“继续”代替批准 |
| 正在做 | 具体动作，不只写内部阶段号 |
| 待决/受阻 | 具体事项、影响范围、责任方；独立工作是否可继续 |
| 已验证与未覆盖 | 检查对象、方法、环境和证据 |
| 下一步/停止点 | 下一动作、恢复条件或本轮已结束 |
| 更新时间 | 真实记录时间 |
