# MR !1 中文覆盖层

来源：内部产品仓库MR !1，提交`21e7066c3013c68150148c04d52390c6c46422d4`，共同基线`7a31e1b10086d55928624a4145b03dbaf25e4533`。

两份完整译文及核心入口的中文元数据、资源定位段落为维护者审核的适配层。metadata.json固定入口输入和译文摘要；未知输入应先评审上游变化，再更新覆盖层与摘要，不能绕过失败直接覆盖。组件、数据、主题与脚本仍按原始设计来源导入。

resource_location_adapter.py在导入链末尾定位资源并应用中文入口；product_stage_adapter.py维护产品启动、导航、文案职责和执行前提。导入后运行build_manifest.py，再按package/VALIDATION.md验证。重新导入不更新业务项目、宿主配置或已安装插件。
