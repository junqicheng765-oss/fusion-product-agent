# rc.14：评测缺陷修复候选

2026-11-10。本地开发候选，基于已发布 rc.12.pr4（313430e），保留 PR #4 设计方法、脚本、图库及已有产品流程。吸收未发布 rc.13 四份产品资源的有效修订；文案资源冲突保留 PR4 同批批准规则，并合入关键语义变化逐项可见的要求。

## 修复内容

- 文案审查摘要覆盖每条关键语义变化及原因；相同原因可列明适用 ID 合并说明，机械排版无需逐句解释。草稿、批准与实屏验证分别记录。
- 重复操作先判断请求是否发出，再判断请求身份及核对范围；已拦截的点击不产生第二笔待核对请求。未知发送事实保留未知，前端防重不冒充服务端幂等。
- 查到记录后依当前业务状态关联文案、允许动作与目标页；反馈、列表、详情、重开保持同一权威事实。迟到回包不能复活已定义终态，不为状态差异重复建页面。
- 人工/离线通道从首份草稿起要求依据；人工处理意愿不证明具体渠道存在，无调用证据不能声称已转交。
- 正式前端复核要求刷新后重建返回上下文及当前可用焦点；正常返回、刷新返回、直接进入与来源目标失效分别验证，记录下一次 Tab 去向。覆盖层及来源清单同步，重导可复现。

## 验证边界

沿用结构、安装/交付和导入回归。局部模型输出、独立接收核对与旧失败前端副本的浏览器验证另留原始证据；这些定向检查不构成全量评测分数或所有未来产物的通过保证。图片查看取证属于评测工具链，单独探针，不将缺事件计为产品能力失败。

未变更冻结评测定义，未改旧执行输出，未覆盖安装缓存。本候选尚未提交、推送、发布或安装；完整复评应固定实际分发包摘要，不能沿用 rc.13 或 rc.12.pr4 成绩。
